# 題目判準

這份文件決定每個候選題目怎麼被評估。你可以隨時修改;修改後,已評估過的題目不會自動重評。

## 限制

- **時間**:<期限,例如一年內完成論文>
- **論文類型**:<理論、實證,或兩者都要>
- **已經確定的事**:<指導教授、資料、領域;沒有就寫「無」>
- **每個候選題目的評估上限**:一次坐下來的時間(約一到兩小時)。到時間還下不了結論,就記為「未定」並寫明還缺哪一項事實。

## 判準

每個候選題目對照以下六項。結果只有三種:符合、不符合、目前無法判斷。

1. **跟得上**:補齊缺少的先備知識大約需要八週以內(依你的期限調整)。
2. **缺口還在**:最近十二個月沒有論文已經把這個問題做完。需要實際查過才算。
3. **有模型也有驗證**:背後有可以寫成數學的機制,而且有現成的資料集、模擬器或測試平台能檢驗模型的預測。
4. **資源拿得到**:需要的資料、軟體、硬體,在不依賴特定人特別提供的情況下拿得到;或者已經確認有人能提供。
5. **期限內做得完**:存在一個最小可交付的版本,能在期限內完成學習、建模、驗證與寫作。
6. **有人能指導**:系上至少有一位教授的研究與它相鄰。

## 說明

- 第 3 項依你的論文類型調整:純理論的論文不需要資料集,純實證的論文不需要數學模型。
- 「夠不夠新」和「夠不夠成為一篇論文」是 agent 的估計。這兩件事最後要問真正的指導教授。
